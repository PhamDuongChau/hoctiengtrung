Xem trang web
⚙️ Kết nối GitHub

Trang này đọc và lưu thẳng các file trong kho (repository) GitHub chứa trang web. Chỉ người có mã truy cập mới lưu được.

Cách tạo mã truy cập (làm một lần)
  1. Mở github.com/settings/personal-access-tokens/new (đăng nhập GitHub nếu được hỏi).
  2. Token name: đặt tên tuỳ ý, vd "Sửa web học tiếng Trung". Expiration: chọn thời hạn (vd 1 năm).
  3. Repository access: chọn Only select repositories → chọn đúng kho chứa trang web.
  4. Permissions → Repository permissions → Contents: chọn Read and write.
  5. Bấm Generate token, sao chép mã (bắt đầu bằng github_pat_) rồi dán vào ô bên trên.

Không gửi mã này cho ai. Nếu lộ, vào GitHub → Settings → Developer settings → Personal access tokens để xoá mã cũ và tạo mã mới.
